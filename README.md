# Plastikey

기계식 키보드를 갖고 싶지만 갖지 못하는 자들에게 필요한 macOS용 앱.

> *제가 쓰고 싶어서 만들었습니다.*

키보드를 치면 기계식 키보드 소리가 납니다. 메뉴바에 아이콘 하나로 지내고, 창은 없습니다.
기본으로 셋팅되어 있는 소리는 "사무용 키보드 Cherry KC 1000" 입니다.
마우스를 눌러도, 패드를 터치해도 '딸-깍' 소리가 납니다.

필요하시면 아래 [소리 바꾸기](#소리-바꾸기) 내용에서 소리를 바꾸시길 추천드립니다.

## 받기

[Releases](../../releases) 에서 `Plastikey-0.1.0.zip` 을 받아 풀고, `Plastikey.app` 을 응용 프로그램 폴더로 옮깁니다. 키 입력을 듣는 앱이니 이 저장소의 Releases 에서만 받으세요.

처음 열면 맥이 막습니다. 애플 공증을 받지 않은 앱이라서 그렇습니다. **시스템 설정 → 개인정보 보호 및 보안** 에서 [그래도 열기] 를 누릅니다.

## 권한

입력 모니터링 하나만 씁니다. 키나 마우스 버튼이 눌린 순간을 알아야 소리를 낼 수 있어서입니다. 앱을 열면 안내가 뜨고, 스위치를 켜면 끝입니다.

어떤 키인지는 소리를 고르는 데만 쓰고 저장도 전송도 하지 않습니다. 인터넷도 쓰지 않습니다.

## 쓰는 법

메뉴바의 키보드 아이콘에서 키보드 소리와 마우스 소리를 각각 켜고 끄고, 음량을 따로 맞춥니다.

## 소리 바꾸기

들어 있는 소리는 공개로 쓸 수 있는 소리를 넣어 둔 것입니다. 마음에 드는 소리를 골라 바꿔 쓰시길 추천합니다.

이 저장소를 받아 `sounds-private/` 폴더에 소리 파일과 `config.json` 을 넣고 `./build.sh --private` 로 빌드합니다. 형식은 [sounds/README.md](sounds/README.md) 에 있습니다. Xcode Command Line Tools 가 필요합니다.

다시 빌드할 때마다 권한이 풀리는 게 싫으면 `scripts/create-signing-identity.sh` 를 먼저 한 번 실행합니다.
